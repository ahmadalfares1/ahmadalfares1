## Featured Project

### E-commerce Sales Analysis & Revenue Forecasting

Analyzed approximately **1 million retail transactions** from the UCI Online Retail II dataset and built a machine-learning pipeline for daily revenue forecasting.

- Cleaned and explored real-world transactional data
- Engineered lag-based time-series features
- Used a date-based train/test split to prevent data leakage
- Compared the model against multiple baseline approaches
- Built a Random Forest regression model
- Achieved **MAE £11,257** compared with **£13,398** for the 7-day-average baseline

[View the project](https://github.com/ahmadalfares1/ecommerce-sales-analysis)
